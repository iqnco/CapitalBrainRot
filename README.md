# Capital BrainRot

**Live:** [capital-brain-rot.vercel.app](https://capital-brain-rot.vercel.app)

A Duolingo-style study game for the Capital Markets course at IE University, dressed in the
Italian brainrot meme aesthetic. You walk a road across a map of Italy, one region per
chapter, answering exam-style questions to unlock the next one.

A map with a road on it is a better reason to open the app than a PDF.

---

## What it does

- **Campaign map.** Nine Italian regions, each one a course chapter: investments
  background in Piemonte, asset classes in Lombardia, how securities trade in Veneto,
  macro and industry analysis in Toscana, equity valuation in Lazio, and so on down the
  boot. Your character walks the road between pins as you progress, and chapters earn up
  to three stars.
- **Four question types:** multiple choice, fill in the blank, typed answers and
  match-the-pairs, mixed in a fixed rhythm so a round never feels samey.
- **Lives and feedback.** Three hearts per round. A wrong answer costs one and shows why
  you were wrong, not just that you were.
- **Roman Ruins.** A separate mode built from the course's problem sets, mock exam and
  past finals.
- **Skibidi Toilet Bowl.** An unlockable endless mode that draws from every question bank.
- **Accounts and progress.** Sign-up, per-chapter progress synced to the cloud, match
  history, stats and a leaderboard.
- **Characters.** Unlockable pixel-art characters, generated with one fixed prompt so
  they all look like they belong to the same game.

## How it's built

| | |
|---|---|
| Framework | Next.js 15 (App Router), TypeScript, Tailwind |
| AI | Claude (`claude-sonnet-4-6`) for question generation, and explanations; OpenAI `gpt-image-1` for character art |
| Data | Supabase for auth, profiles, progress and the leaderboard |
| Content | Question banks built from course material (PDF and DOCX parsing with `pdf-parse` and `mammoth`) |
| Hosting | Vercel |

A few decisions worth pointing at:

- **Real questions over generated ones.** Question banks are extracted from actual course
  material and exams. Claude generates extra questions and writes explanations, but the
  core practice is the real thing, because practising on questions that don't look like
  the exam is how you do well in the app and badly in the exam.
- **Forked, not rewritten.** It started as a fork of my
  [Rainbow Study Siege](https://github.com/iqnco/rainbowStudySiege), the same engine with
  a different course and a completely different skin. Swapping the theme without
  touching the quiz logic is a good test of whether the engine was built cleanly.
- **An AI agent team.** Design work ran through four defined roles in
  [`.agents/`](.agents/TEAM.md): creative director, game designer, lead engineer and
  content lead. A feature went pitch, refine, estimate, decide, build, review. It's a small
  experiment in running a product process with AI collaborators instead of just prompting
  for code.
- **Asset pipeline as code.** Map art, character sprites and backgrounds are generated by
  scripts in [`scripts/`](scripts/), so the whole art style can be regenerated rather than
  hand-edited.

## Running it locally

```bash
npm install
cp .env.local.example .env.local   # add ANTHROPIC_API_KEY (plus Supabase and OpenAI keys for accounts and art)
npm run dev                        # http://localhost:3000
```
